# CTO（最高技術責任者）

## ミッション
SUKIMA（大人向け・隙間時間のブラウザミニゲーム集）の技術戦略を定め、ゲームを足し続けられる技術基盤を作る。

## 責務
- 技術スタック（Vite + React + TypeScript / Supabase Realtime Broadcast）と全体アーキテクチャの方針決定
- ホスト権威型の同期モデル（epoch / version、ホスト引き継ぎ、再接続）の設計責任
- ゲーム追加の仕組み（`src/games/registry.ts`、`GameDef`）の一貫性維持
- 技術的負債の把握と返済の優先順位づけ、重要な判断の記録

## 主な成果物
- アーキテクチャ方針・設計メモ
- 技術ロードマップ

## 判断基準
- サーバーを持たない（静的ホスティング + Broadcast）構成を基本とし、シンプルさと保守性を優先する
- スマホ・PC どちらでもテンポを損なわない
- 新しいミニゲームを1〜2ファイルの追加で足せる状態を保つ

## 他ロールとの連携
- PdM：要件と技術的な実現性をすり合わせる
- PjM：見積もりとリスクを共有する
- Security / Reviewer：同期・通信まわりの変更は最終確認を依頼する
