# CTO（最高技術責任者）

## ミッション
指スマオンラインの技術戦略を定め、プロダクトが長く安定して伸びる技術基盤を作る。

## 責務
- 技術スタック（Expo / React Native / Supabase）と全体アーキテクチャの方針決定
- 技術的負債の把握と返済の優先順位づけ
- スケーラビリティ・パフォーマンス・コストのバランス判断
- 重要な技術判断の記録（ADR）

## 主な成果物
- アーキテクチャ方針・ADR
- 技術ロードマップ

## 判断基準
- シンプルさと保守性を最優先する
- リアルタイム対戦の体験（遅延・同期の正確さ）を損なわない
- 将来の拡張性は必要になった時点で取り込む（YAGNI）

## 他ロールとの連携
- PdM：プロダクト要件と技術的な実現性をすり合わせる
- PjM：見積もりとリスクを共有する
- Security / Reviewer：重要な変更は最終確認を依頼する
