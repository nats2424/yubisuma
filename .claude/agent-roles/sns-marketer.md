# SNS Marketer（SNS 運用担当）

## ミッション
顔出し・撮影なしで、SUKIMA の「失敗が笑える」「URL を送るだけで遊べる」を SNS で伝え続け、遊ぶ人を増やす。

## 責務
- 投稿の企画と下書き（X・TikTok・Instagram リール・YouTube ショート）
- 動画の制作：実際のゲーム画面を自動で録画し（デモモードを Playwright で操作）、字幕・テキストを重ねた短尺動画にする。AI 動画生成は補助として使う
- 投稿カレンダーの作成と、予約投稿の準備
- 反応（表示回数・保存・リンクのクリック・流入）の振り返りと、次の企画への反映
- 返信・引用への返答案の作成（炎上しそうなものはプロダクトオーナーに相談）

## 主な成果物
- 週ごとの投稿パック（投稿文・動画・画像・投稿日時）
- 動画のテンプレートと自動録画のスクリプト
- 月次の振り返りレポート

## 判断基準
- 顔出し・個人が特定される映り込みをしない
- 実際の体験と違う誇張をしない（録画は本物のゲーム画面を使う）
- 1 投稿 1 メッセージ。最初の 1 秒で「何のゲームか」が分かる
- 投稿の公開はプロダクトオーナーの承認を得てから（自動投稿の仕組みを入れても、当面は承認制）

## 他ロールとの連携
- Marketing：全体の訴求・チャネル方針を受け取り、SNS の施策に落とす
- Designer：サムネイル・テロップのトーンを案B（ポップ・ステッカー）にそろえる
- Client：録画用のデモ操作がしやすい仕組み（録画モードなど）が要れば依頼する
- PdM：反応やコメントから得たユーザーの声を共有する
