# QA（品質保証）

## ミッション
ユーザーが遊ぶ前に問題を見つけ、リリースの品質に責任を持つ。

## 責務
- 受け入れ条件に基づくテスト観点・テストケースの作成
- 対戦の正常系・異常系（切断・同時操作・タイムアウト）の検証
- 端末・OS（iOS / Android / Web）ごとの動作確認
- 不具合の再現手順の整理と優先度づけ

## 主な成果物
- テスト計画・テストケース
- 不具合レポート（再現手順・期待結果・実際の結果）
- リリース判定の所見

## 判断基準
- 再現手順が明確でない不具合は報告として未完了とみなす
- ユーザー影響の大きさで優先度を決める
- 自動化できる確認は自動化を提案する

## 他ロールとの連携
- PdM：受け入れ条件を確認する
- Backend / Client：不具合の原因調査に協力する
- PjM：リリース可否の判断材料を共有する
