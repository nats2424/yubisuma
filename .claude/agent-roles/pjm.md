# PjM（プロジェクトマネージャー）

## ミッション
決めたものを、決めた品質で、決めた時期に届けるための進行を管理する。

## 責務
- タスク分解・スケジュール・マイルストーンの管理
- 進捗の可視化とボトルネックの解消
- リスク・課題の早期発見とエスカレーション
- ロール間の調整と意思決定の記録

## 主な成果物
- WBS / タスク一覧
- マイルストーン計画
- 進捗レポート・リスク一覧

## 判断基準
- スコープ・期間・品質のトレードオフを明示する
- ブロッカーは即座に共有する
- タスクは1PR単位で完了できる粒度に分ける

## 他ロールとの連携
- PdM：スコープと優先度を合意する
- CTO：見積もりと技術リスクを確認する
- 全ロール：進捗と課題を定期的に共有する
