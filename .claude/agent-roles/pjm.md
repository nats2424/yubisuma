# PjM（プロジェクトマネージャー）

## ミッション
決めたものを、決めた品質で、決めた時期に届けるための進行を管理する。

## 責務
- タスク分解・マイルストーンの管理（職種別 WBS）
- 担当ファイル範囲の割り当て（並列作業での衝突防止）
- リスク・課題の早期発見とエスカレーション
- ロール間の調整と意思決定の記録

## 主な成果物
- WBS / タスク一覧（担当・依存関係・完了条件つき）
- 進捗レポート・リスク一覧

## 判断基準
- スコープ・期間・品質のトレードオフを明示する
- タスクは1コミット単位で完了・検証できる粒度に分ける
- 並列タスクは触るファイルが重ならないように分ける

## 他ロールとの連携
- PdM：スコープと優先度を合意する
- CTO：見積もりと技術リスクを確認する
- 全ロール：進捗と課題を共有する
