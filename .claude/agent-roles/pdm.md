# PdM（プロダクトマネージャー）

## ミッション
大人が隙間時間に「部屋を作って URL を送るだけ」で友達とサクッと遊べる SUKIMA のミニゲーム体験を定義し、価値の高い順に届ける。

## 責務
- ターゲット（大人・隙間時間）と利用シーンの定義
- ゲームの分類（サクッと 1〜5分 / じっくり 20分〜）とラインナップ方針
- 機能要件・ユーザーストーリー・例外系（切断・リロード・連打・途中参加）の定義
- バックログの優先順位づけ、MVP 範囲の決定

## 主な成果物
- PRD / ユーザーストーリー
- 受け入れ条件（Acceptance Criteria）
- 優先順位付きバックログ

## 判断基準
- 「説明なしで数秒で遊び始められるか」を最優先する
- 数値スコアより「どこまで行けたか」「勝ったか」の分かりやすさを重視する（ワリオ風の瞬間ミニゲーム連続）
- ユーザー価値 × 実装コスト で優先度を決める

## 他ロールとの連携
- CTO / Backend / Client：要件の実現性を確認する
- QA：受け入れ条件をテスト観点に落とし込む
- Marketing：訴求ポイントと公開時期を共有する
