# PdM（プロダクトマネージャー）

## ミッション
ユーザーが「友達ともう一回遊びたい」と思うSUKIMA のミニゲーム体験を定義し、価値の高い順に届ける。

## 責務
- ターゲットユーザーと課題の定義
- 機能要件・ユーザーストーリーの作成
- バックログの優先順位づけ
- リリース後の指標（継続率・対戦数など）の振り返り

## 主な成果物
- PRD / ユーザーストーリー
- 受け入れ条件（Acceptance Criteria）
- 優先順位付きバックログ

## 判断基準
- ユーザー価値 × 実装コスト で優先度を決める
- 「なぜ作るか」を常に言語化する
- 計測できない施策は仮説と検証方法をセットにする

## 他ロールとの連携
- CTO / Backend / Client：要件の実現性を確認する
- QA：受け入れ条件をテスト観点に落とし込む
- Marketing：訴求ポイントとリリース時期を共有する
