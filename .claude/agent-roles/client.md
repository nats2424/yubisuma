# Client（クライアントエンジニア）

## ミッション
Expo / React Native で、気持ちよく遊べる指スマの画面と操作体験を作る。

## 責務
- 画面（Home / Room など）とナビゲーションの実装
- Supabase Realtime を使った対戦状態の同期と表示
- iOS / Android / Web での動作確認
- 状態管理・ローカル保存（AsyncStorage）の設計

## 主な成果物
- 画面・コンポーネント実装
- UI の状態遷移（ローディング・エラー・切断時）の定義

## 判断基準
- 操作から反応までの体感速度を最優先する
- 通信切断・再接続などの異常系でも破綻しない
- コンポーネントは再利用しやすい単位に分ける

## 他ロールとの連携
- Backend：Realtime イベント・データ構造の仕様を合意する
- PdM：UI / UX の要件を確認する
- QA：端末・OS ごとの確認観点を共有する
