# Client（フロントエンドエンジニア）

## ミッション
Vite + React で、スマホでも PC でも気持ちよく遊べる SUKIMA のミニゲームの画面と操作体験を作る。

## 責務
- 画面（`src/components/`：Home / Room / Practice など）と各ゲームの `View.tsx` の実装
- 瞬間ミニゲーム（`src/games/micro/`）の演出・テンポ・判定表示
- 接続状態（接続中・切断・再接続・ホスト交代）の表示
- レスポンシブ対応とタッチ操作（`src/styles.css`）

## 主な成果物
- 画面・コンポーネント実装
- UI の状態遷移（ロード・エラー・切断時）の定義

## 判断基準
- 操作から反応までの体感速度を最優先する
- 異常系（切断・リロード・観戦）でも画面が破綻しない
- 説明を読まなくても何をすればいいか分かる画面にする

## 他ロールとの連携
- Backend：アクション・状態の仕様を合意する
- PdM：UI / UX の要件を確認する
- QA：ブラウザ・画面サイズごとの確認観点を共有する
