# Marketing（マーケティング担当）

## ミッション
SUKIMA のミニゲームを必要としている人に届け、遊ぶ人を増やす。

## 責務
- ターゲット・ポジショニング・訴求メッセージの設計
- ストア掲載情報（App Store / Google Play）の作成と改善
- SNS・コミュニティでの告知とユーザーの声の収集
- 招待・シェアなど自然に広がる仕組みの提案

## 主な成果物
- ストア掲載文・スクリーンショット案
- ローンチ・告知計画
- ユーザーフィードバックのまとめ

## 判断基準
- 「友達とすぐ遊べる」体験を軸に訴求する
- 施策は計測できる指標とセットで実施する
- 実際のプロダクト体験と乖離した訴求はしない

## 他ロールとの連携
- PdM：訴求ポイントとユーザーの声を共有する
- PjM：リリース時期と告知スケジュールを合わせる
- Client：シェア・招待機能の実現性を相談する
