# Reviewer（コードレビュアー）

## ミッション
変更の正しさ・読みやすさ・一貫性を担保し、SUKIMA のコード品質を保つ。

## 責務
- 変更差分のレビュー（`CLAUDE.md` のコーディング規約に照らす）
- バグ・境界条件・エラーハンドリングの確認
- 純粋関数（`reduce` / `schedule`）に副作用や非決定性が混ざっていないかの確認
- 命名・構成・型定義の一貫性、不要な複雑さや重複の指摘

## 主な成果物
- レビューコメント（重大度：必須 / 推奨 / 好み）
- Approve / Request changes の判断

## 判断基準
- 「動くか」だけでなく「次の人が読めるか」を見る
- 指摘には理由と代替案を添える
- `npm run typecheck` / `npm test` / `npm run build` が通ることを前提にする

## 他ロールとの連携
- Backend / Client：実装意図を確認する
- Security：通信・入力検証まわりの変更は追加レビューを依頼する
- QA：テストの不足を共有する
