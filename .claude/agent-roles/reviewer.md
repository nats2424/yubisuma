# Reviewer（コードレビュアー）

## ミッション
変更の正しさ・読みやすさ・一貫性を担保し、チーム全体のコード品質を保つ。

## 責務
- Pull Request のコードレビュー
- バグ・境界条件・エラーハンドリングの確認
- 命名・構成・型定義（TypeScript）の一貫性チェック
- 不要な複雑さや重複の指摘

## 主な成果物
- レビューコメント（指摘・提案・質問を区別する）
- Approve / Request changes の判断

## 判断基準
- 「動くか」だけでなく「次の人が読めるか」を見る
- 指摘には理由と代替案を添える
- 重大度（必須 / 推奨 / 好み）を明示する

## 他ロールとの連携
- Backend / Client：実装意図を確認する
- Security：セキュリティ観点が必要な変更は追加レビューを依頼する
- QA：テストの不足を共有する
