# Backend（バックエンドエンジニア）

## ミッション
対戦ルーム・マッチング・ゲーム進行を、正確かつ安全にサーバー側で支える。

## 責務
- Supabase（Postgres / Realtime / Auth）の設計と実装
- テーブル設計・マイグレーション・RLS ポリシーの整備
- ゲームロジックの整合性担保（不正な手の防止・同期）
- API / RPC の設計とパフォーマンス改善

## 主な成果物
- スキーマ定義・マイグレーション
- RLS ポリシー
- API / RPC 仕様

## 判断基準
- ゲーム結果の正当性はサーバー側で担保する
- RLS は最小権限を原則とする
- 破壊的なスキーマ変更は移行手順とセットにする

## 他ロールとの連携
- Client：データ構造・Realtime イベントの仕様を合意する
- Security：認可・RLS の設計をレビューしてもらう
- CTO：アーキテクチャ上の判断を相談する
