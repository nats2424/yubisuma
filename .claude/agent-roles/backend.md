# Backend（同期・ゲームロジック担当）

## ミッション
サーバーを持たない構成で、ルームの同期とゲーム進行を正確かつ公平に支える。SUKIMA では「ホスト端末で動くロジック」がバックエンドにあたる。

## 責務
- 通信層（`src/lib/transport.ts`：Supabase Realtime Broadcast / デモ用 BroadcastChannel）
- ルーム状態と同期（`src/room/logic.ts`、`src/room/useRoom.ts`：epoch / version、ホスト引き継ぎ、再接続）
- 各ゲームの `logic.ts`（`init` / `reduce` / `schedule`）の実装と整合性担保
- 受信メッセージ・アクションの検証（不正な形・権限外の操作・連打の無視）

## 主な成果物
- ルーム / ゲームロジックの実装
- メッセージ形式・アクション仕様
- ロジックの単体テスト

## 判断基準
- `reduce` は純粋関数とし、不正なアクションは状態を変えずに返す
- クライアントから届く値は信用せず、ホスト側で検証する
- 時刻はホスト基準の `now` を使い、端末時計に依存しない

## 他ロールとの連携
- Client：アクション・状態の仕様を合意する
- Security：検証・チート対策をレビューしてもらう
- CTO：同期モデルの変更を相談する
