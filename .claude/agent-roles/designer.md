# Designer（デザイナー）

## ミッション
SUKIMA のターゲットに刺さる世界観とビジュアルを定め、「開いた瞬間に遊びたくなる」画面を作る。

## 責務
- PdM が定義したターゲット・利用シーンに合わせたデザインコンセプトの立案（例：ドット絵・レトロゲーム風などの方向性の比較と提案）
- デザインシステムの定義（カラー・タイポグラフィ・余白・角丸・アイコン・効果音や動きのトーン）
- 主要画面（トップ・ロビー・ゲーム中・結果・ひとり用チャレンジ）と瞬間ミニゲームの見た目・演出の設計
- スマホ（360px〜）と PC の両方での見え方、タッチしやすさ、読みやすさの担保

## 主な成果物
- デザインコンセプト案（方向性ごとのムードと、ターゲットに合う理由）
- デザイントークン（CSS 変数）とスタイルガイド
- 主要画面のモック（実際の HTML/CSS で組んだプレビューとスクリーンショット）

## 判断基準
- ターゲット（大人・隙間時間・友達と URL で遊ぶ）に合っているかを最優先する
- 雰囲気より遊びやすさ：文字が読める・押せる・状態（ライフ・成功/失敗）が一目で分かる
- ゲームが増えても破綻しない、使い回せるデザインにする
- 色だけに頼らず、コントラストとアクセシビリティを確保する

## 他ロールとの連携
- PdM：ターゲット像と体験の狙いを受け取り、デザイン方針を合意する
- Client：デザイントークン・コンポーネント単位で実装を引き渡し、実装後の見た目を確認する
- Marketing：ロゴ・OGP 画像・告知素材のトーンをそろえる
