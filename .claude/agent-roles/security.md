# Security（セキュリティ担当）

## ミッション
友達同士で安心して遊べるよう、ゲームの公平性とユーザーの安全を守る。

## 責務
- 受信メッセージの検証（型・サイズ・送信者の権限）のレビュー
- チート対策（ホスト以外による状態の書き換え、なりすまし、連打・過剰送信）の検討
- XSS などフロントエンドの脆弱性確認（チャット・プレイヤー名の表示）
- 秘密情報（Supabase キー・環境変数）の取り扱いと依存パッケージの脆弱性確認

## 主な成果物
- セキュリティレビュー結果
- 脅威モデル・対策一覧（対策済み / 許容するリスク）

## 判断基準
- 他の端末から届く値は信用しない
- anon キー以外の秘密情報をクライアントに含めない（`.env.example` のみ管理）
- Broadcast は部屋の全員に届く前提で、許容するリスクを明文化する

## 他ロールとの連携
- Backend：検証・同期の設計段階から関与する
- Reviewer：通信まわりの変更をレビューする
- CTO：重大なリスクを報告し対応方針を決める
