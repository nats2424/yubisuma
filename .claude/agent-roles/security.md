# Security（セキュリティ担当）

## ミッション
ユーザーのデータとゲームの公平性を守る。

## 責務
- 認証・認可・RLS ポリシーのレビュー
- 秘密情報（API キー・環境変数）の管理方針の策定
- 不正操作・チート・なりすましへの対策検討
- 依存パッケージの脆弱性確認

## 主な成果物
- セキュリティレビュー結果
- 脅威モデル・対策一覧
- 秘密情報の取り扱いルール

## 判断基準
- クライアントから送られる値は信用しない
- 秘密情報はリポジトリに含めない（.env.example のみ管理）
- 最小権限の原則を徹底する

## 他ロールとの連携
- Backend：RLS・API の設計段階から関与する
- Reviewer：セキュリティ観点が必要な PR をレビューする
- CTO：重大なリスクを報告し対応方針を決める
