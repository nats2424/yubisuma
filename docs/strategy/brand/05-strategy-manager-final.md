## 残った論点

1. **WATTO の最大の不確かさは商標（スター・ウォーズの権利者）。** PO の J-PlatPat の確認が済むまで、SNS の登録と Designer の仕上げは始めない
2. **名前で検索されない**のは WATTO の構造的な弱点。受け入れて進める（名前より中身で見つけてもらう）
3. 5 秒テストは PO の知り合いが相手で甘めに出る。外れの検出しかできない
4. 試遊（D-47）と SNS 開始の日付の前後関係が未定（PjM）
5. PATTO に切り替えたら、一言の約束 A「ぱっと」と名前が重なるので、シート 2 は「その場が、明るくなる。」か C に変える必要がある
6. 各 SNS の自己紹介の文字数の上限は【要確認】（今の文は収まる見込み）
