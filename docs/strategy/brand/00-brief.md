# 00. ブリーフ：どんなブランドを築くか（オーケストレーター、2026-11-22）

## 問い（PO の言葉）
「どんなブランドを築くか、というブランドイメージを固めてからの方が良いか？」（2026-11-22。SNS・YouTube の立ち上げを前に）

## なぜ今か
- D-36 で SNS は作品名ではなく**作り手の名義**に決めたが、名前（D-53）が未定。チャンネル名・アカウント名・プロフィール・動画の見た目・一言の口調が、すべてここに依存する
- 作品は今後も増える（NORTH_STAR）。SUKIMA は 1 作品目で、ブランドは作品をまたいで続く
- 一度名前とトーンで発信を始めると、変えるコストが大きい（フォロワーの再認知、アカウント名の変更）

## 決めたいこと
1. **ブランドの芯**：誰のための・何を約束する作り手か（NORTH_STAR §2 のビジョン「遊んだ人がワクワクしたり、会話が弾んだりして、その場が明るくなる」を、受け手の言葉に直す）。一言の約束（タグライン）案
2. **人格と口調**：作り手の一人称の語り口（顔・実声なし、D-36）。何を言い、何を言わないか
3. **見た目の方向**：SUKIMA の案 B「ポップ・ステッカー」との関係（作り手のブランドと作品のブランドを分けるか、つなげるか）。ロゴ・色・動画のテンプレートの最小限
4. **名前の候補**（D-53）：作り手の名義の名前 5〜10 案と、各 SNS・ドメインでの空き状況の確かめ方。商標の衝突の簡易チェック
5. **競合との違い**：Qdan（ワードウルフ・どこパ・BoardGameJoin）、オインクゲームズ、We're Not Really Strangers など（`marketing/sns/research/2026-11-reference-accounts.md`）との位置の違い
6. **最初に必要な最小限**：SNS を始めるのに今決める必要があるものと、後でよいもの

## 前提・制約
- NORTH_STAR：PO は週 4 時間・営業しない・普段は実名/顔/声を出さない。遊ぶ人は無料。大人中心だが子どもが遊んでもよい
- D-25・D-46：最優先の場面は「集まっているときのスキマ時間（対面）」。D-63：見せ方の先頭はラッシュ・反射神経・多数派
- 予算は月 0〜5,000 円。商標の出願などの費用が要るなら別に PO 判断
