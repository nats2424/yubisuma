## 3. 5 秒テストより先に SNS を始めるか（PdM P-1）と PO の時間

### 3.1 論点

- 試遊（D-47、Phase 0）の時期と SNS を始める時期のどちらが先か、01・02 とも日付で書いていない。**SNS が先なら、5 秒テストの結果は名前を決めた後に出る。**
- PdM の推奨 (a)「今決めて始め、外れたら切り替える」は、「フォロワーが少ないうちは切り替えが安い」が根拠。ただし切り替えの費用は**フォロワーではなく PO と Designer の手間**（5 つの SNS のハンドル・表示名の変更、アイコン・ヘッダー・動画の締めのカードの作り直し）で、ここが見積もられていない。
- (b)「上位 2 つのハンドルを両方押さえる」は「10 分ほど」とあるが、実際はアカウントの登録（メール・電話の確認）が 2 名前 × 4〜5 SNS で 8〜10 個になる。10 分では収まらない見込み【仮定：30〜60 分】。使わないアカウントを持ち続ける手間もある。

### 3.2 Strategy Manager の見立て

**(a) に賛成。ただし「関門 1〜3 を机の上で通してから始める」を条件にする。**

- PO が WATTO を気に入っており、5 秒テスト（PO の知り合い 15〜30 人【仮定：02】、遊んだ直後で甘めに答える）は、もともと「どちらが優れているか」を示せない（PdM §2.2 の限界）。役割を「**明らかに外れていないか**（電力の会社に見える・怪しい、が多くないか）」の確認に絞れば、SNS を先に始めても困らない。
- 外れて切り替えるときに大きいのは関門 1〜2（衝突・商標）での失敗で、これは 5 秒テストではなく机の上で先に分かる。**だから先に机の上の確認を済ませることが、PO の時間をいちばん守る**（NORTH_STAR §5 の 1）。
- 切り替えの判定線（5 秒テストで何が何割なら変えるか）は、PdM 案（②「怪しい」20% 未満【仮定】）に、WATTO 用に「①で電力・電気の会社と答えた人が半数以上なら見直す【仮定】」を足す。

### 3.3 PO の時間（04 で見積もる）

01・02 とも、PO の作業時間が手順ごとに書かれていない。04 で次を【仮定】付きの分で出す：ブランドシートを見て選ぶ／ハンドルの空きを見る（WATTO と代わり 1 つ）／J-PlatPat を見る／アカウントを作る／プロフィールを貼る。合計が 1 週の 4 時間の何割になるかを書く。**AI でできる部分（検索・手順書・下書き）は AI に寄せ、PO の作業は「開いて見る」「登録する」「選ぶ」だけにする。**

## 4. 04 で Marketing が直すこと（番号付き）

**05 はブランドシート 8 項目の形で出すので、04 は 8 項目それぞれの材料をそろえる形で書く。**
