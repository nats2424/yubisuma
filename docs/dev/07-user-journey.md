### 4.4 PdM の所見

- **J-01〜J-06 は済み**で、URL が届いた瞬間（OGP・共有文）と結果の後（次の行動）は埋まった。対面を主にしたことで、新しく弱いのは**「同じ部屋の人を集める」（QR がない）**と**「最初の 1 回で分かる」（ルールが文章で、お手本がない）**の 2 つ。
- 新しい Must は **J-27（QR）・J-26（ひと言）・J-07（最初の 1 本をラッシュに）の 3 件で、工数はいずれも S〜M**。公開前（Phase 0 の試遊の前）に入れたい。D-14 で承認された Must 8 件の外なので、PO の確認が要る。
- 「ルールを感覚で分かる」は、まず安い順に J-26（文言と表示）→ J-07（既定ゲーム）→ J-30（絵）→ J-29（やることカード）→ J-31（練習）と積む。J-29 は時間で進むゲームの開始を遅らせる必要があり、Backend の作業が入るので Should にした。
- 通話（SC-4）向けに上げていた J-18・J-25 は Could に下げた。J-15 の通話併用の確認は残すが、優先しない。
