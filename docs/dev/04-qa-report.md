## 4. 不具合票（Q-05）

優先度：**必須** = 公開を止める／**推奨** = 公開前（AC-M の前）に直したい／**次フェーズ** = Should や設計上の既知の限界。重大度はユーザー影響（高・中・低）。

**修正担当へ**：対応するテストは `it.skip` で、テスト名に票 ID が入っている。**修正後に skip を外し**、`npm test` で通ることを確かめてから QA に再確認を依頼すること。

### QA-BUG-01：引き継ぎ判定の猶予（接続・復帰から 9 秒）が、ホストの bye／ホストからの sync にも効いてしまう

| 項目 | 内容 |
| --- | --- |
| 重大度 / 優先度 | 中 / **推奨** |
| 担当 | Backend |
