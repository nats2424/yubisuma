# 私たちが向かう方向（North Star）

> **状態：PO 確認済み（2026-11-11）**。すべてのエージェントは、仕事を始める前にこのファイルを読む。
> 変えるのはプロダクトオーナー（PO）だけ。食い違う計画を見つけたら、どの役割でも指摘する。

## 1. 私たちは何者か
- 1 人のプロダクトオーナーと、役割を分けた AI エージェントでできた小さな組織。
- PO は**副業**として、**週 4 時間**で関わる。AI は、PO の時間を使わずに済む仕事を最大限引き受ける。

## 2. ビジョン
**遊んだ人がワクワクしたり、会話が弾んだりして、その場が明るくなるプロダクトを作る。そうして、みんなの人生と時間を明るくする。**

- 私たちが作るのは「その場を明るくする」プロダクト。ゲームに限らない。
- 1 つで終わらず、プロダクトを次々に作っていく。積み重ねてビジョンに近づく。
- 収入の目標：**営業せずに、恒久的に入り続ける収入**。最初の目安は「事業全体で手取り月 20 万円」。期限は決めつけず、実績を見て見直す（Q2・Q5・Q7）。収入はビジョンを続けるための手段で、目的ではない。

## 3. SUKIMA の役割
- **1 作品目**。ビジョンに向けた最初のプロダクト。
- **最優先の役割：SNS のフォロワー（＝次のプロダクトを届けられる人たち）を増やすこと**。SUKIMA で生まれた「その場が明るくなった」体験を発信し、私たちを知ってもらう。
- 次の役割：少ない人の時間で、AI の組織がプロダクトを作り・運用し・広める型を確かめる（2 作品目以降に使い回す）。
- **SUKIMA 単体で大きく稼ぐことは求めない**。費用を自分で賄えれば十分で、稼ぎは作品が増えたときの事業全体で考える。

### 判断のものさし（SUKIMA）
1. 遊んだ人の場が明るくなったか（会話が弾んだか・笑いが起きたか・また遊びたいと思ったか）
2. それが SNS で伝わり、フォロワーが増えたか
3. 費用を賄えているか

## 4. 守ること（制約）
| 制約 | 内容 | 出どころ |
| --- | --- | --- |
| 時間 | PO は週 4 時間まで（SNS の確認・承認を含む） | Q3 |
| 営業しない | 人に会って売り込む・商談する・人脈に頼る形の収益にしない | Q3・Q6 |
| 名前の出し方 | 普段の発信・運営は実名・顔・声を出さない。ただし**必要なタイミング（販売に伴う法定表示・請求時の開示・決済や登録の本人確認など）では実名を出してよい** | Q4・PO の発言（2026-11-11） |
| 遊ぶ人は無料 | 遊ぶために払う必要は誰にもない（「無料で全部遊べる」が強み） | PO の発言（D-20 案） |
| 予算 | 稼ぎが出るまでは月 0〜5,000 円程度。Supabase の費用上限を外すのは稼ぎが出てから | Q8・D-21 |
| 体験を壊さない | 課金・広告で、遊んでいる場の空気を壊さない。対象は大人中心だが、子どもが遊んでくれてもよい（個人情報は集めない） | PO の発言・D-28 案 |

## 5. 判断の優先順位（迷ったら上を優先）
1. PO の時間を増やさない（AI で回せない仕事は、仕組みを変えるか、やらない）
2. 遊ぶ人の体験を壊さない
3. **自分たちで回る（セルフサーブ）**：買う人が説明なしで買える、使う人が説明なしで使える
4. 実測で判断する（仮説は仮説と書き、検証の方法と時期を添える）
5. 費用を小さく保つ

## 6. やらないこと
- 対面・通話での営業、人脈頼みの販売、受託
- 遊ぶための課金、プレイ中の広告
- 根拠のない数字での約束（数字には出典か「仮定」を付ける）

## 7. 組織としての動き方

- PO の判断が必要なことは `docs/DECISIONS.md` に集める。
- 各役割の担当範囲・作業場所は CLAUDE.md の「エージェント運用」に従う。
- このファイルと食い違う計画を見つけたら、どの役割でも指摘する。
