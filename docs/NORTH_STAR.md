# 私たちが向かう方向（North Star）— 下書き

> **状態：下書き（2026-11-11）**。プロダクトオーナー（PO）が確定するまで、各エージェントは参考として読む。
> `【要確認】` の部分は PO にしか決められない。確定したら、すべてのエージェントが仕事を始める前にこのファイルを読む。

## 1. 私たちは何者か
- 1 人のプロダクトオーナーと、役割を分けた AI エージェントでできた小さな組織。
- PO は**副業**として、**週 4 時間**で関わる。AI は、PO の時間を使わずに済む仕事を最大限引き受ける。

## 2. 目指すところ（ビジョン）
- 長期：【要確認】SUKIMA の先にある「より大きなビジネスプラン」は何か。SUKIMA はその**足がかり**（Q7）。
- 収入の目標：**営業せずに、恒久的に入り続ける収入**。最初の目安は「事業全体で手取り月 20 万円」。期限は決めつけず、実績を見て見直す（Q2・Q5・Q7）。

## 3. SUKIMA の役割（なぜ今 SUKIMA を作るのか）
【要確認】次のどれ（複数可）を SUKIMA に期待するか。それによって、何を最優先にするかが変わる。
- (a) **それ自体で稼ぐ**プロダクトにする
- (b) **集客の土台**（ユーザー・SNS のフォロワー・メールなどの接点）を作り、次の事業に流す
- (c) **仕組みの実験場**：AI エージェントの組織で、少ない人の時間でプロダクトを作り・運用し・広める型を確かめる
- (d) **実績・ポートフォリオ**として次の事業の信用にする

## 4. 守ること（制約）
| 制約 | 内容 | 出どころ |
| --- | --- | --- |
| 時間 | PO は週 4 時間まで（SNS の確認・承認を含む） | Q3 |
| 営業しない | 人に会って売り込む・商談する・人脈に頼る形の収益にしない | Q3・Q6 |
| 匿名 | 実名・顔・声を出さない。氏名が公表される手続き（インボイス登録など）が要る取引はしない | Q4 |
| 遊ぶ人は無料 | 遊ぶために払う必要は誰にもない（「無料で全部遊べる」が強み） | PO の発言（D-20 案） |
| 予算 | 稼ぎが出るまでは月 0〜5,000 円程度。Supabase の費用上限を外すのは稼ぎが出てから | Q8・D-21 |
| 品位 | 大人が開いて恥ずかしくない。課金・広告で体験を壊さない | 06・D-28 案 |

## 5. 判断の優先順位（迷ったら上を優先）
1. PO の時間を増やさない（AI で回せない仕事は、仕組みを変えるか、やらない）
2. 遊ぶ人の体験を壊さない
3. **自分たちで回る（セルフサーブ）**：買う人が説明なしで買える、使う人が説明なしで使える
4. 実測で判断する（仮説は仮説と書き、検証の方法と時期を添える）
5. 費用を小さく保つ

## 6. やらないこと
- 対面・通話での営業、人脈頼みの販売、受託
- 実名が必要な取引
- 遊ぶための課金、プレイ中の広告
- 根拠のない数字での約束（数字には出典か「仮定」を付ける）
