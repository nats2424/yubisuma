# SUKIMA — 隙間時間のミニゲーム集

部屋を作ってURLを送るだけで、友達とすぐ遊べるブラウザゲームサイトです。スマホ・PC両対応、登録不要。

## 遊べるゲーム

| ゲーム | 人数 | 時間 | 内容 |
| --- | --- | --- | --- |
| 🐺 ワードウルフ | 3〜10人 | 約5分 | 1人だけ違うお題を持つ「ウルフ」を会話で見つける |
| ⚖️ 多数派ゲーム | 3〜10人 | 約3分 | 2択の質問で「みんなが選ぶ方」を当てる |
| ⚡ 反射神経バトル | 1〜10人 | 約1分 | 画面が緑になった瞬間にタップ。5ラウンドの合計タイムで勝負 |
| 👍 指スマ | 2〜8人 | 約3〜5分 | 親指の合計を当てて、先に両手を下ろした人から上がり |

ルーム内にチャットあり（スマホでは右下のボタンから開く）。

## 開発

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # ゲームロジックのテスト
npm run build      # dist/ に静的ファイルを出力
```

Supabase を設定しない場合は**デモモード**になり、同じブラウザの別タブ同士でだけ遊べます（動作確認用）。

## 友達と遊べるようにする（Supabase の設定）

通信には Supabase Realtime の Broadcast 機能だけを使います。**テーブル作成やSQLは不要**です。

1. [Supabase](https://supabase.com/) で無料プロジェクトを作成
2. Project Settings → API から `Project URL` と `anon public` キーをコピー
3. `.env.example` を `.env.local` にコピーして値を設定

```
VITE_SUPABASE_URL=https://xxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJ...
```

※ Realtime の設定で「Private channels only（公開チャンネルを禁止）」を有効にしている場合は無効にしてください。

## 公開（デプロイ）

`npm run build` で出力される `dist/` は静的ファイルだけなので、Vercel / Netlify / Cloudflare Pages / GitHub Pages などにそのまま置けます。
環境変数 `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` をホスティング側にも設定してください。
GitHub Pages のようにサブパスで公開する場合は `VITE_BASE=/yubisuma/` も設定します。

## しくみ

- **ホスト権威型**：部屋を作った人（ホスト）の端末がゲームの状態を持ち、他の人の操作を受け取って状態を更新し、全員に配信します。サーバー側のプログラムは不要です。
- **ホスト交代**：ホストが閉じる・電波が切れると、約10秒後に参加順で次の人が自動でホストを引き継ぎます。状態は全員が持っているのでゲームはそのまま続きます。
- **再接続**：リロードしても同じプレイヤーとして復帰します（タブごとにIDを保持）。
- **注意**：通信内容は部屋の全員に届くため、開発者ツールを使えばワードウルフのお題などは覗けてしまいます。友達同士で遊ぶ前提の設計です。

## ゲームの追加方法

`src/games/<名前>/` に以下を作り、`src/games/registry.ts` に登録します。

- `logic.ts` — `init`（開始時の状態）、`reduce`（操作で状態を更新する純粋関数）、必要なら `schedule`（時間経過で進めるアクション）
- `View.tsx` — 状態を表示し、`send(action)` で操作を送るReactコンポーネント

`reduce` はホスト端末でだけ実行されるので、乱数を使っても全員の結果は一致します。
